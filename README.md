# Hello World — MERN Bootcamp Day 1

## 🎯 Project Overview
My very first project in the MERN Stack Bootcamp. This is a personal 
introduction page built with vanilla HTML, CSS, and JavaScript. It 
showcases the four technologies I'm learning and serves as proof of 
my development environment setup.

## ✨ Features
- Responsive card layout using CSS Grid
- Hover animations with CSS transitions
- Dynamic date display using JavaScript
- Mobile-friendly responsive design
- Clean, accessible semantic HTML

## 🛠️ Tech Stack
- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, Grid layout, CSS custom properties
- **JavaScript (ES6)** — Dynamic content and DOM manipulation

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required for this project

### View Locally
1. Clone the repository
```bash
   git clone git@github.com:sarhad3D/hello-world-mern-bootcamp.git
```
2. Navigate to the project directory
```bash
   cd hello-world-mern-bootcamp
```
3. Open `index.html` in your browser
